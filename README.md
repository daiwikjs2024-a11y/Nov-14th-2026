# Two Idiots in Love 🌙

A responsive anniversary website for Prithika and Daiwik.

## Files
- `index.html` — the page and story
- `style.css` — responsive design and animations
- `script.js` — interactive reasons, quiz, navigation, and hidden message
- Includes pasta date ideas, dark chocolate references, and a long-distance section with reassurance promises
- `assets/` — the four supplied photos

## Preview locally
Open `index.html` in a browser.

## Publish with GitHub Pages
1. Create a new GitHub repository (for example, `prithi-anniversary`).
2. Upload the contents of this folder to the repository root. Keep `index.html`, `style.css`, `script.js`, and `assets/` together.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch `main` and folder `/ (root)`, then Save.
6. Wait for the Pages URL to appear in Settings → Pages.

No build step or framework is required. Google Fonts are used for typography; the page otherwise works as a static site.
